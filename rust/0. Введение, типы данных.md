### Cargo

Создание:
```bash
cargo new <project-name>
```

Запуск:
```
cd project-name
cargo run
```

### Переменные
1. Скалярные:
- u8 / u16 / u32 / u64 / u128
- i8 / i16 / i32 / i64 / i128
- isize // arch dependent (like int in C)
- usize // Используется для индексов и длины массивов
- f32/f64
- bool
- char // **Unicode!!!**

2. Композитные:
- Кортежи: могут содержать элементы разных типов.
```rust
let my_tuple: (i8, char, bool) = (1, 'f', false);
let i_var: i8 = my_tuple.0;
```

- Array (static)
```rust
let arr: [i32, 3] = [1,2,3];
let elem0: i32 = arr[0];
println!("{}", arr);  // Выведет: [1,2,3]
```
