### Функция

Точка входа в программу:
```rust
fn main() {
}
```

```rust
fn test(value: i8) -> i8 {
  value + 1 // if no ; -> returns automatically
}
```

### if / else / else if

```rust
fn main() {
  let i: i32 = 1;
  if i == 1 {
    println!("true");
  } else if i == 2 {
    println!("false");
  } else {
    println!("none");
  }
}
```

### loops
1. loop - бесконечный цикл, остановка с помощью break

```rust
    let mut i: i32 = 0;
    loop {
        if i == 32 {
            break;
        }

        i += 1;
    };
```


Можно возвращать значение из break:
```rust
    let mut i: i32 = 0;
    let res: i32 = loop {
        if i == 32 {
            break i;
        }

        i += 1;
    };

    println!("{}", res); // 32
```
