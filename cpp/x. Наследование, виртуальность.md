## Принципы ООП

1. **Наследование** – это механизм, посредством которого один класс может наследовать свойства(поля и методы) другого. Наследование позволяет строить иерархию классов, переходя от более общих к более специальным. В С++ есть множестенное наследование - у класса может быть несколько базовых классов.
2. **Инкапсуляция** — механизм языка, ограничивающий доступ к компонентам класса(методам и атрибутам), делает их защищенными или приватными, то есть доступными только внутри объекта.
3. **Полиморфизм** — это способность одного и того же объекта или функции принимать разные формы в разных контекстах. В C++ есть два типа полиморфизма:
   - **Compile time**: он реализуется с помощью перегрузки оператора класса или функций. На этапе компиляции компилятор сам решает, какая функция/оператор должна быть вызвана.
   - **Run time**: какую функцию вызвать решается во время выполнения программ. Достигается путем виртуальных функций.


## Модификаторы доступа
- `private` - переменные и функции могут быть использованы внутри базового класса, не видны вне базового класса(при наследовании или использовании в коде программы).\
- `protected` - переменные и функции видны в классе-наследнике, но не видны вне класса и класса-наследника.\
- `public` - переменные и функции видны в классе-наследнике и вне класса.\

## Конструкторы и деструкторы
В C ++ конструкторы и деструкторы не наследуются. Однако они вызываются, когда дочерний класс инициализирует свой объект. Конструкторы вызываются один за другим иерархически, начиная с базового класса и заканчивая последним производным классом. Деструкторы вызываются в обратном порядке.

```cpp

class Device {
    public:
        Device() {}
        ~Device() {}
};

class Computer: public Device {
    public:
        Computer() {}
        ~Computer() {}
};

class Laptop: public Computer {
    public:
        Laptop() {}
        ~Laptop() {}
};

int main() {
   Laptop lt;
}
// Device() -> Computer() -> Laptop()
// ~Laptop() -> ~Computer() -> ~Device()
```
