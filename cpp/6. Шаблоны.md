# 6. Шаблоны

## Перегрузка функций

Рассмотрим:
```cpp
int max(int a, int b) {
	if (a < b) {
    return b;
  }

  return a;
}


max(1,2); // 2
max(1.2, 2.1); // 2, т.к. double -> int и дробная часть обрежется.
```

Количество и типы аргументов функции должны быть известны заранее, на этапе компиляции. Но в языке C++ можно создавать функции с одним и тем же именем, но разным набором или типами аргументов и с разными телами. Такие функции называются перегруженными.

```cpp
bool compare(int a, int b) {}
bool compare(double a, double b) {}
bool compare(double a, double b, double c) {}
```

Но недопустимо менять тип возвращаемого значения, так как компилятор не сможет определить, какую из функций вызвать(например возвращаемое значение игнорируется):

```cpp
int f(int a) {}
double f(int a) {} // compile error
```

## Шаблоны

Чтобы не перегружать функцию для каждого типа данных, придуманы шаблоны функций.

Шаблоны — это фрагменты обобщённого кода, в котором некоторые типы или константы вынесены в параметры. Шаблонными могут быть функции, структуры (классы) и даже переменные. Компилятор превращает использование шаблона в конкретный код, подставляя в него нужные параметры на этапе компиляции. Шаблоны позволяют писать общий код, пригодный для использования с разными типами данных.

```cpp
template <typename T> 
T Max(const T& x, const T& y) { 
  if (x > y) { 
    return x; 
  } else { 
    return y; 
  } 
}
```

Class/template - нет различий.

Пусть есть два вызова функции:
```cpp
Max<std::string>(“abc”, “bcd”);
Max<int>(1, 2);
Max<double>(1.2, 2.3);
```

Можно не задавать в угловых скобках тип данных, т.к. компилятор сам проверит тип аргумента, и сделает инстанцирование (будет создано две различных функции):

```cpp
double Max(const double &x,  const double &y) {};
int Max(const int &x,  const int &y) {};
```

Для std::string нужно явно указать, иначе const char *.

В спорных ситуациях Max(1.2, 2) будет ошибка компиляции, так как компилятор не поймет к какому типу приводить, int или double. Нужно явно указать <double>.

Важно понимать, что, (a)  и (b) несмотря на общий шаблон, разные функции, которые просто порождаются компилятором по образцу.

Перегрузка шаблонных функций:

Шаблоны функций также можно перегружать. Например, если нужно изменить логику функции для векторов:

// перегрузка для векторов 
```cpp
template <typename T> 
const std::vector<T>& Max(const std::vector<T>& v1, const std::vector<T>& v2) 
{ 
  if (v1.size() > v2.size()) { 
    return v1; 
  } else if (v1.size() < v2.size()) { 
    return v2; 
  } else if (v1 > v2) { 
    return v1;
  } else { 
    return v2; 
  } 
}
```
