# 5. Функции, лямбда-функции

Аргументы сложных типов (векторы, строки, любые контейнеры, большие структуры) всегда лучше передавать в функцию по константной ссылке, если функция использует их только для чтения.

В отличие от аргументов, значения сложных типов можно без проблем возвращать из функций. Здесь от ненужного копирования (по крайней мере, для стандартных контейнеров) спасает copy elision(?).

Опасно возвращать из функции ссылку на локальную переменную, так как эта ссылка сразу же станет «висячей»: компилятор в таких случаях генерирует warning.

## Лямбда-функции

Иногда бывает неудобно определять отдельную именованную функцию.Тогда можно определить анонимную лямбда-функцию прямо в месте ее использования:

```cpp
auto func = []() {} -> T.
```

В [] задается контекст - сюда можно прокинуть значения из внешней области видимости.

В () передаются аргументы, как и в обычных функциях.

В {} содержится тело функции.

-> T - возвращаемое значение. Можно не указывать, компилятор сам определит его на этапе компиляции.

Пример:
```cpp
auto sum_int = [](int &a, int &b) -> int {
	return a + b;
};

int a = 1;
int b = 2;
std::cout << sum_int(a, b) << std::endl; // 3
std::cout << sum_int(1, 2) << std::endl; // compile error, обычная ссылка int &ref должна ссылаться на изменяемый обьект.
```

[&] — захват по ссылке, все переменные в автоматическом хранилище объявлены в области охвата 

[=] — захват по значению, значение копируется (во время определения лямбда функции)

[x, & y] — явно захватывает x по значению, а y по ссылке
