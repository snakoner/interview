# 4. Ссылки и указатели различия

Указатель -  специальный тип данных, который может хранить адрес какой-либо другой переменной в памяти.

Ссылки позволяют вводить псевдонимы для переменных.Ссылка - особый вид указателя, который автоматически разыменовывается.

## Различия

1. Указатели ссылаются на адрес в памяти, ссылки ссылаются на объект в памяти
2. Ссылка не может быть неинициализированной, указатель может:
```cpp
int &x; // compile error
int *x; // OK
```
3. У ссылки нет нулевого значения:
```cpp
int &x = 0; // compile error
int *x = 0; // OK
```
4. Ссылку нельзя переинициализировать, указатель можно.
```cpp
int a = 1, b = 2;
int *p = &a; // указывает на a
p = &b; // теперь указывает на b
int &x = a;	// указывает на a
x = b;		// теперь переменная a хранит значение b, а не x ссылается на b
```
5. Нельзя получить адрес ссылки и ссылку на ссылку:
```cpp
int a = 1;
int &x = a;
int &&xx = x;	// compile error
```

6. Нельзя создавать массив ссылок:
```cpp
int &x[10] = {}; // compile error
```

7. Для ссылок не арифметики


## Const
Константа — это переменная, предназначенная только для чтения. Её значение должно быть зафиксировано в момент присваивания. При этом оно не обязательно должно быть известно в момент компиляции:

```cpp
int a;
std::cin >> a;
const int c = a * 2;
```

Можно создавать константные ссылки и указатели - значения, на которые они ссылаются нельзя изменять:
```cpp
int x = 42; 
int& ref = x;  // обычная ссылка 
const int& cref = x;  // константная ссылка 

++x;  // OK 
++ref;  // OK 
++cref;  // ошибка компиляции: псевдоним cref предназначен только для чтения 

int* ptr = &x;  // обычный указатель 
const int* cptr = &x;  // указатель на константу 

++*ptr;  // OK 
++*cptr;  // ошибка компиляции: разыменованный cptr — константа!
```

Для константных переменных можно использовать только константные указатели и ссылки:
```cpp
const int cx = 42; 
int& ref = cx;  // ошибка компиляции: константность нельзя убрать 
const int& cref = cx;  // OK 
int* ptr = &cx;  // тоже ошибка компиляции 
const int* cptr = &cx;  // OK
```

Следует различать `const T *` и `T *const`: 
в первом случае нельзя изменить переменную, на которую ссылается T, во втором случае переменную изменить можно, но нельзя переназначить указатель на другую переменную.

```cpp
int x = 42;
const int cx = 13;
 
int* ptr = &x;  // обычный указатель
ptr = &cx;  // ошибка компиляции
 
const int* cptr = &x;  // OK: через *cptr нельзя будет изменить x
cptr = &cx;  // OK
 
int* const ptrc = &x;  // OK: *ptrc можно менять, но сам ptrc менять нельзя
ptrc = nullptr;  // ошибка компиляции
 
const int* const cptrc = &x;  // OK, для &cx тоже бы сработало
```
