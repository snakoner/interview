# 12. Жизненный цикл объектов

Кроме конструктора, можно определить еще несколько специфических функций класса:
1. конструктор копирования: он вызывается при создании копии другого объекта; 
2. оператор присваивания: вызывается при присваивании нового значения уже существующему объекту; 
3. деструктор: вызывается при уничтожении объекта.

Если их не определить явно, то компилятор сгенерирует тривилальные функции.

## Деструкторы

Автоматически вызываются при выходе из области видимости объекта. Так как объекты класса создаются на стеке (если не использовать new), то деструкторы будут вызываться в порядке обратном порядку создания данных объектов: для первого созданного объекта деструктор будет вызван в последнюю очередь:
```cpp
int main() {
  T t1;
  T t2; 
}

// t1 constructor
// t2 constructor
// t2 destructor
// t1 destructor
```

Можно создавать объекты и в куче, для этого есть оператор new(обязательно вызывать delete, иначе произойдет утечка памяти).

## Конструктор копирования и оператор присваивания

```cpp
T t1;
T t2 = t1;
```

В данном случае будет вызван один конструктор и один конструктор копирования и два деструктора.

```cpp
T t1;
T t2;

t2 = t1;
```

Будет вызван конструкторы для t1, t2 и оператор присваивания для t2 + 2 деструктора.


Дефолтный конструктор копирования просто вызывает аналогичные конструкторы копирования для всех полей класса. Аналогично, дефолтный оператор присваивания вызывает операторы присваивания для полей.

Важно понимать разницу между конструктором копирования и оператором присваивания. Конструктор копирования создаёт новый объект, а оператор присваивания модифицирует уже существующий.


## Статические поля и функции

`static` в объявлении поля в классе обозначает, что значение этого поля одинаково для всех объектов класса. Фактически, статическое поле является глобальной переменной, которую просто поместили в класс как в пространство имён.

Чтобы сразу проинициализировать поле, нужно использовать inline:
```
class Test {
public:
	inline static x = 1;
}

std::cout << Test::x << std::endl;		// 1

Test::x = 2;
Test t1;
Test t2;

std::cout << t1.x << “ “ << t2.x << std::endl; // 2 2
```

**Статическая функция** — это просто обычная функция, которую поместили в класс как в пространство имен по семантическим соображениям. В отличие от функции из класса она не принимает неявным образом текущий объект, но может обращаться к статическим полям.

```cpp
class Test {
public:
  inline static x = 1;
	static void f(int y) {
	  std::cout << y << std::endl;
  }
}

Test::f(2); 		// 2
```

## Временные объекты

Например, мы хотел вызвать такую функцию:

```cpp
void f(const T& t) {

}

f(T());
```

Здесь мы передаём в функцию f временный объект T(). У него нет имени. Он существует лишь пока вычисляется выражение. 

В C++ имеется возможность различать в функциях временные и обычные объекты. Напишем перегруженную версию функции f, принимающую на вход так называемую rvalue-ссылку:

```cpp
void f(const T& t) {

}
```

// для временных объектов
```cpp
void f(T&& t) {

}
```
