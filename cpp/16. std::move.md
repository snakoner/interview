## lvalue, rvalue

**lvalue** - выражение, описывающий не временный объект, чаще всего именованный. У этого выражения можно взять адрес и, возможно, записать в него. (То, что может быть по левую стороны от =).

**rvalue** - выражение, описыввающее временный объект или return-выражение. (То, что может быть по правую сторону от =)

Так же есть ссылки lvalue reference(T&) и rvalue reference(T&&).

Разделение на rvalue ref и lvalue ref позволяет перегружать конструкторы копирования (перегрузка с && - конструктор перемещения) и оператор присваивания(оператор перемещения). В данном случае мы избегаем копирования, и в случае, если передана rvalue ref(временный объект), то мы просто может "забрать" его указатели и присвоить их новому объекту.

Пример:
```cpp
// если объект был передан по lvalue ссылке, то вызовется конструктор копирования
string(const string& other) : data_(new char[other.size() + 1]), size_(other.size()) {
    std::memcpy(data_, other.data_, sizeof(char) * other.size());
}

// если объект был передан по rvalue ссылке, то вызовется конструктор перемещения
string(string&& other) : data_(other.data_), size_(other.size()) {
    other.data_ = nullptr; // заполнение валидными значениями, так как объект продолжает существовать
    other.size_ = 0;
}
```

Со временными объектами в случае если есть перегруженная по rvalue ref функция/оператор/метод/ctor будет вызваны соответствующие перегруженные функции. Но что, если есть lvalue объект, и после вызове некоторой функции его значение нам уже не нужно. Для этого можно использовать std::move - используется для указания того, что объект t может быть "перемещён из" (обычное указание компилятору, какую перегрузку использовать).

> Зачем в конструкторе перемещения присваивать перемещаемому объекту нулевые значения? Чтобы в деструкторе не было повторного освобожение перемещаемого объекта.
