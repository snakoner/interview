# 9. Алгоритмы на контейнерах
Алгоритмы на контейнерах

```cpp
#include <algorithm>
```

Здесь есть функции поиска, подсчета, сортировки. Обычно принимают на вход два итератора, которые ограничивают указанный диапазон.

К итераторам есть два требования:
1. Это итераторы одного и того же контейнера.
2. От одного элементы к следующему можно перейти с помощью ++ для итератора.

Предполагается, что последний итератор = c.end() и его нельзя разыменовывать.

На итераторах реализован цикл range-based-for. 
```cpp
for (const auto& element : container) { 
// делаем что-то с element 
} 
```

просто преобразуется компилятором в примерно такой код: 

```cpp
for (auto iter = container.begin(); iter != container.end(); ++iter) { 
  const auto& element = *iter; 
  // делаем что-то с element 
}
```

## Подсчет

```cpp
std::vector<int> v = {2, 7, 1, 8, 2, 8}; 
std::cout << std::count(v.begin(), v.end(), 8) << std::endl;  // 2
```

Можно применять к любому последовательному контейнеру.

## Поиск

Последовательный перебор, возвращает итератор на найденный элемент, иначе итератор на конец интервала:

```cpp
std::find(v.begin(), v.end())
```

Для map, unordered_map нельзя использовать, так как std::find принимает итератор на пару, а в map нам second неизвестен.
Для них можно использовать:
```cpp
m.find(key);
```

## Алгоритмы с предикатом _if

```cpp
std::find_if(it1, it2, [](const auto &a) {
	return a > 10;
});
```

`find_if`, `count_if`
`all_of` - все элементы удовлетворяют предикату
`any_of` - хотя бы один удовлетворяет
`none_of` - ни один не удовлетворяет

## Алгоритмы, меняющие последовательность

Так как все эти алогоритмы работают с итераторами, они могут лишь менять последовательность, но не изменять ее размер и удалять элементы. Если нужно, то это надо делать вручную.

`std::reverse`
`std::unique` - переупорядочивает уникальные элементы в начало, возвращает итератор на оставшиеся элементы.
`std::fill` и `std::generate` (заполнение заданными значениями), 
`std::rotate` (циклический сдвиг), 
`std::replace` (замена элементов), 
`std::remove` (переупорядочивание элементов, чтобы указанный элемент не встречался в начале), 
`std::shuffle` (случайная перестановка элементов).

## Запись в другую последовательность

```cpp
std::copy(from_begin_it, from_end_it, to_begin_it)
std::vector<int> v = {1,2,3,4,5};
std::list<int> l;

l.resize(v.size()); // 0,0,0,0,0

std::copy(v.begin(), v.end(), l.begin());
```

Теперь в list: 1,2,3,4,5.

В контейнере, куда мы копируем, должно быть достаточно места для копирования, иначе UB

## Адаптеры для вставки

`std::back_inserter(container)` - адаптер. Ведет себя как итератор, но при попытке записи в него делает push_back в контейнер.

```cpp
std::vector<int> v = {1,2,3,4};
std::list<int> l;

l.resize(v.size());

std::copy(v.begin(), v.end(), std::back_inserter(l));
```

Также есть:
`std::front_inserter`
`std::inserter` - кроме контейнера принимает еще и итератор, куда надо начать вставлять элементы.

## Сортировка

`std::sort` - нестабильный алгоритм. Если нужно сохранить порядок элементов, то можно воспользоваться std::stable_sort - работает за	 O(n (log n)2).

`std::sort` требует, чтоб контейнер был с произвольным доступом: `vector`, `string`, `deque`, `array`.

Для списков и ассоциативных контейнеров есть метод sort, которая под капотом использует merge_sort.

Для проверки того, что контейнер отсортирован, можно использовать `std::is_sorted`.

Над отсортированными последовательностями можно выполнять операции:
1. слияния (std::merge)
2. объединения (std::set_union) 
3. пересечения (std::set_intersection)
4. разности (std::set_difference)
5. симметрической разности (std::set_symmetric_difference). 
6. Также можно проверять вложения (std::includes).
