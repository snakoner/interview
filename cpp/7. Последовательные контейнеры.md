## std::array

Если нужен массив фиксированного размера, размер которого известен на этапе компиляции, можно использовать `array` - обертка над `T[N]`:

```cpp
std::array<int, 3> point = {1, 2, -3};
```
Предоставляет интерфейс стандартного контейнера: `size(), front(), back(),, begin(), end(), at()`...

Элементы array располагаются последовательно в памяти, но хранятся на стеке(т.к. T[N]).

Размеры array в runtime менять нельзя.


## std::deque

Double-ended queue, можно вставлять/удалять из конца и начала.
Располагаются кусочно-непрерывно, в отдельных страницах памяти. Даже для хранения одного элементы в деке будет выделена целая страница. Сами страницы не обязательно расположены в памяти подряд.

Эффективно вставлять/удалять из начала и конца, причем старые элементы останутся на тех же адресах в памяти. Но при вставке/удалении из других мест будет производится сдвиг(копирование)

Обращение по индеку за O(1), так как размер страниц фиксирован и известен адрес первой страницы.

Доступны push_front/back, pop_front/back.

Преимущества над vector:
1. push_front и push_back выполняется за O(1) всегда.

```cpp
std::deque<int> d;
d.push_back(1);

int value = d.pop_back(0);
int value = d[1];

for(auto &x : d) {}
```

## std::list

Двусвязный список. Узлы могут хранится в памяти по разным адресам, не обязательно последовательно.

Для списка доступен range-based-for.

Отличие от дека в способе хранения нод. Можно эффективно вставлять/удалять в начало и конец. Вставка в другое место и доступ к произвольному элементу O(n).


## std::forward_list

Односвязный список. Можно добавлять после какого-то узла, удалять после какого-то узла, вставлять и удалять из начала за O(1). 

`push_front, pop_front, insert_after, erase_after`.

## Итераторы
Итераторы — это специальные объекты, предназначенные для навигации по контейнеру. Итераторы позволяют обращаться к текущему элементу контейнера и сдвигаться к соседним элементам. 

`container.begin()` - итератор на начальный элемент.
`container.end()` - итератор, указывающий за последний элемент контейнера, при разыменовывании undefined behaviour.

Указатели на роль итераторов подойдут только для контейнеров, которые хранят ноды в памяти последовательно (vector, string, array).

В отличие от итераторов для последовательных контейнеров, к итераторам с не непрерывным хранением ячеек в памяти нельзя прибавить произвольное число, можно лишь сделать ++.

`std::next(it) `- вернет итератор на следующий элемент контейнера.
`std::prev(it)` - вернет итератор на следующий элемент контейнера.
`std::advanced(it, 2)` - вернет итератор через два от текущего.

Итераторы имеют тип:
```cpp
std::string::iterator;
std::vector<int>::iterator;
```

### Инвалидация итераторов, ссылок, указателей.

Если контейнер изменяется, то в некоторых случаях итераторы и ссылки (указатели) на элементы могут стать невалидными.
Например, если `std::vector` имел size = 4, capacity = 4 и произошел `push_back`, то старый итератор указывает на старую область памяти.

Такое может произойти у `vector, string, deque`(так как может произойти некоторая реаллокация внутри одной страницы).
Все ок для `array, list, forward_list.`

Для обращении по инвалидированным итераторам/указателям/ссылкам - undefined behaviour.
