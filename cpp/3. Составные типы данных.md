# 3. Составные типы данных

## Перечисления
Перечисления — это удобный способ описывать однотипные именованные константы. По умолчанию перечисления хранятся как тип `int`, а их значения последовательно нумеруются с нуля.
```cpp
enum class Color { 
  White, 
  Red, 
  Orange, 
  Blue, 
};
```

Можно менять значения enum:
```cpp
enum class Color { 
  White, 
  Red, 
  Orange = 20, 
  Blue, 
};
```

Тогда будет 0, 1, 20, 21.

### Преобразования:

```cpp
int value = static_cast<int>(color2);  // 3 
Color color3 = static_cast<Color>(2);  // Color::Orange
```

## Структуры

Если нужно объединить данные в одну сущность, есть структуры:
```cpp
struct Point {
	float x;
	float y;
};
```

### Инициализация
```cpp
Point p = {1.2, 3.4};
```

### Начиная с C++20
```cpp
Point p = {.x = 1.2, .y = 3.4};
```
> Важно, чтобы названия переменных шли в том же порядке. Пропущенные значения будут инициализироваться значениями по умолчанию.

### Выравнивание

Рассмотрим структуру:
```cpp
struct Point {
  	int x;
	int y;
	char c;
};

std::cout << sizeof(int) << std::endl;	// 4
std::cout << sizeof(char) << std::endl;	// 1
std::cout << sizeof(Point) << std::endl’	// 12
```

Компилятору удобнее работать со структурой 12 байт, при условии, что внутри этой структуры есть переменные, размер которых — 4 байт. Выравнивание происходит по самому длинному элементу.

## Кортежи и пары
```cpp
#include <utility>

std::pair<std::string, int> p = {“Hello”, 1};
```

Обращение к первому и второму элементу:
```cpp
p.first, p.second;
```

```cpp
std::tuple<int, std::string, bool> t = {1, “Hello”. true};
```

Получение i-го элемента:
```cpp
std::get<0>(t);
```

Важно понимать, что типы элементов пары или кортежа, а также размер кортежа фиксируются на этапе компиляции.
