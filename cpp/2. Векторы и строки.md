# 2. Векторы и строки

## Векторы

```cpp
#include <vector>
```

`std::vector` называется динамический массив, обеспечивающий быстрое добавление новых элементов в конец и меняющий свой размер при необходимости. Гарантирует отсутствие утечек памяти.

Инициализация вектора:
При помощи списка инициализации:

```cpp
std::vector<int> v = {1,2,3,4};
```

Вектор заданной длины и хранящий нули:

```cpp
std::vector<int> v(10);
```

Вектор заданный длины, хранящий заданное значение:

```cpp
std::vector<int> v(5, 2);
// {2,2,2,2,2}
```

Обращение к элементам:

```cpp
v[i]     // проверка того, что i < v.size() не происходит, если неверно, то undefined behaviour
v.at(i)  // происходит проверка, если неверно, то исключение std::out_of_range, возвращает ссылку

// На пустом векторе - undefined behaviour
v.front()  // 0 элемент вектора (ссылка)
v.back()   // последний элемент (ссылка)
```

Размер вектора:

```cpp
size_t size = v.size(); - возвращает size_t (совпадает с uint32_t или uint64_t в зависимости от битности платформы).
```

Нужно быть осторожным, когда размер вектора 0:
```cpp
for(size_t i = 0; i < v.size() - 1; i++)
```

В данном случае v.size() = 0, v.size() - 1 = 0xffffffff, поэтому i < v.size() - 1 будет верно, пока i < 0xffffffff. Можно сделать так:
```cpp
for(size_t i = 0; i + 1 < v.size(); i++)
```

Вставка удаление элементов:
```cpp
push_back()         // добавление в конец         // O(1)
pop_back()         // удаление из конца -         // O(1)
insert(int pos)   // вставка на позици  ю po// - O(n)
erase(int pos)   // удаление из поз  иции po// - O(n)
clear()         // удалени        // вектора
```

### Аллокация

Если `size == capacity`, то происходит реаллокация размером `capacity * 2`.

`reserve()` - резервирование памяти.

```cpp
std::vector <int> v;
v.reserve(10) // size = 0, capacity = 10
```

Если сделать reserve на size1, но size0 > size1 - ничего не поменяется.


`resize()` - изменение размеров вектора:

```cpp
std::vector <int> v(10, 5);
v.resize(4); // capacity = 10, size = 4;
```

### Многомерные векторы

Создание двумерного вектора m * n, m - строки, n - столбцы:

```cpp
std::vector<std::vector<int>> v2(m, std::vector<int>(n));
```

### Сортировка

```cpp
#include <algorithm>

std::sort(data.begin(), data.end());
std::sort(data.rbegin(), data.rend()); // в обратном порядке с помощью обратных итераторов
```

### Поиск

Можно воспользоваться find из пакета algorithm:

```cpp
std::find(vec.begin(), vec.end(), item) != vec.end()
```


## Строки

Контейнер `std::string` можно рассматривать как особый случай вектора символов `std::vector<char>`, имеющий набор дополнительных функций:

Добавление в конец: 
```cpp
s += 'x';
```

Получить подстроку:
```cpp
std::string sub1 = s.substr(5, 6);
```

Подстрока с 12-й позиции и до конца
```cpp
std::string sub2 = s.substr(12);
```

Позиция первого пробела символа:
```cpp
size_t pos1 = s.find(' ');
```

Позиция первой подстроки 
```cpp
size_t pos3 = s.find("str");
```
