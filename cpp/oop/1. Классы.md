## Общие определения

**Класс** - определенный пользователем тип данных, включающий в себя данные и функции(методы), доступ к которым регулируется с помощью модификаторов доступа private, protected, public. По умолчанию все члены класса private.

Отличие методов от функций:
1. Методы вызываются в контексте объекта
2. У методов есть неявный параметр this - указатель на объект, к которому применяется метод.
3. Методы могут обращаться к private полям класса.

Отличие struct от class:
1. Технически структура отличается от класса только тем, что в struct поля по умолчанию public, в классе private.
2. Но если говорить про реальное использование, то структуры используют просто для объединения полей, консистентность которых не нужно контролировать, классы - если поля связаны с друг другом и эту связь нужно контролировать.

```cpp
struct Point {
  int x;
  int y;
}; // нам неважно, как связаны x и y



class Route{
public:
  std::string getSource() { return source; }
  // ...

private:
  std::string source;
  std::string dest;
  float length;
}; // здесь нужно контролировать source и dest, так как от них зависит length


```

## Конструкторы

Вызываются при создании объекта в зависимости от сигнатуры. Если явного конструктора в классе нет, то компилятор сам добавит конструктор по умолчанию:
```cpp
class Route {
  Route() {} // компилятор добавит конструктор по умолчанию
};
```

В случае, если в классе есть какой-то конструктор, отличный от дефолтного, то вызвать конструктор без параметров уже не получится: компилятор его не добавит:

```cpp
class Route {
  Route(const std::string& src, const std::string& dest) {
    source = src;
    dest = dest;
  }
};

Route r; // compile error
Route r1("Moscow", "Saint-Petersburg"); // ok
```

Если есть некоторая функция, куда передается объект, то можно использовать {}, компилятор сам создаст объект и передаст его в функцию:

```cpp
  void PrintRoute(const Route& r) {}

  PrintRoute({"Moscow", "Saint-Petersburg"});
```

Аналогично с возвращаемым значением:

```cpp
  Route getRoute() {
    // Route r("Moscow", "Saint-Petersburg");
    // return r;

    return {"Moscow", "Saint-Petersburg"}; // компилятор сам создаст объект
  }
```

## Деструкторы

Вызываются при уничтожении объект(когда выходим за область видимости объекта) неявно, явно вызвать деструктор нельзя.
Редко объявляются явно, но если нужно например, чтобы освободить выделенную память, закрыть файлы, то нужно объявлять деструктор явно.
Если деструктор не объявлен, то компилятор добавит дефолтный конструктор.
