### IP - Internet protocol (3 level)

Передача данных:
1. Без гарантии доставки (получатель не отправит никаких сообщений, если пакет не был получен, это
возлагается на проколы высших уровней).
3. Без порядка следования пакетов

Используется без установки соединения, пакет сразу шлется.

Зачачи:
1. Объединение сетей
2. Маршрутизация
3. Качество обслуживания(?)

Пакет:

<img width="578" alt="Снимок экрана 2024-10-02 в 15 24 05" src="https://github.com/user-attachments/assets/d5e7a92a-5b9e-4401-bfe1-c450b72438e6">

- Номер версии: ipv4(4 байта, нехватка), ipv6(16 байт, вводится в эксплуатацию).
- Длина заголовка: обязательная часть + опциональная часть
- Тип сервиса: не используется
- Общая длина: заголовок + данные, максимальное значение 65535 (на практике ограничен 1500 байт)
- Идентификатор пакета, флаги, смещение фрагмента: используются для фрагментации
- Время жизни(TTL): максимальное время, в течение которого пакет может гулять по сети. Сейчас TTL измеряется в прохождении  через 1 маршрутизатор (1 маршрутизатор отнимает 1 TTL). 

- Тип протокола: TCP, UDP, ICMP
- Контрольная сумма: только заголовка
