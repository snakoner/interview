### Виды оборудования:
1. Концентратор(hub), работает на 1 уровне. Рассылает входящий пакет всем подключенным устройствам. В настоящее время вытеснен коммутатором.
2. Коммутатор(switch), работает на 2 уровне(Ethernet). Рассылает входящий пакет только необходимому устройству исходя из таблицы маршрутизации(MAC).
3. Маршрутизатор(роутер), работает на 3 уровне(IP). Рассылает входящий пакет только необходимому устройству исходя из таблицы маршрутизации(IP).

### IP - Internet protocol (3 level)

Передача данных:
1. Без гарантии доставки (получатель не отправит никаких сообщений, если пакет не был получен, это
возлагается на проколы высших уровней).
3. Без порядка следования пакетов

Используется без установки соединения, пакет сразу шлется.

Зачачи:
1. Объединение сетей
2. Маршрутизация
3. Качество обслуживания(?)

- Номер версии: ipv4(4 байта, нехватка), ipv6(16 байт, вводится в эксплуатацию).
- Длина заголовка: обязательная часть + опциональная часть
- Тип сервиса: не используется
- Общая длина: заголовок + данные, максимальное значение 65535 (на практике ограничен 1500 байт)
- Идентификатор пакета, флаги, смещение фрагмента: используются для фрагментации
- Время жизни(TTL): максимальное время, в течение которого пакет может гулять по сети. Сейчас TTL измеряется в прохождении  через 1 маршрутизатор (1 маршрутизатор отнимает 1 TTL). 

- Тип протокола: TCP, UDP, ICMP
- Контрольная сумма: только заголовка

### ICMP (Internet Control Message Protocol)

Так как IP не гарантирует доставку сообщений, то был введен ICMP:
- оповещение об ошибках на сетевом уровне
- тестирование работоспособности сети

Протокол не обязан обрабатывать ICMP сообщения.

#### Типы сообщений
Есть два типа сообщений: запрос-ответ, сообщений без запроса.
1.
- 0/8 - эхо-запрос/эхо-ответ
- 13/14 - запрос/ответ отметки времени

2. 
- 3 - узел назначения не достижим
- 5 - перенаправление маршрута
- 11 - истечение времени жизни пакета

Генерируются сетевым оборудованием.

Но например можно использовать `ping` для эхо типов сообщений.
`traceroute` - определяет маршрут от отправителя к получателю:

[PC] -> [router 1] -> [router 2] -> [router N]

Сначала PC отправляет IP сообщение с TTL=1, router 1 отправляет ICMP с типом 11(время жизни истекло).
Далее PC отправляет IP с TTL=2 и т.д.
