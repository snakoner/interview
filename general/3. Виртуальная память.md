## Общие понятия

Зачем нужна?
1. Нет необходимости программисту вручную согласовывать использование памяти. Линковщику также нет необходимости смотреть, куда класть ту или иную секцию.
2. Изоляция пространства процеса
3. Возможность использовать больше памяти, чем размер RAM

Физический адрес - адрес в RAM, к которому может обращатсья процессор или устройство.
Виртуальный адрес - адрес, видимый процессом. Программа обращается к памяти по виртуальному адресу, а MMU транслирует данный адрес в физический.

Если посмотреть на виртуальные адреса двух разных процессов, то можно увидеть, что их адресные пространства перекрываются. Например, main начинается с адреса 0x1000, стек процесса находится в одном и том же месте, но каждый виртуальный адрес отображается в различные области физической памяти.

В современных ОС система на начальном этапе грузит не все сегменты в RAM, а например одну страничку text, stack, и подгружает их с диска по мере необходимости.
Размер памяти процесса ограничен схемой адресации (сколько бит адрес в системе), а не тем, какого размера RAM. В теории, если размер RAM - 32mb, то 32gb программа может быть запущена. ОС будет постоянно выгружать и подгружать необходимые страницы с диска в RAM.

Resident set - часть процесса, которая находится в RAM в настоящий момент. Описывается rss.
Virtual memory - сколько процесс может занять памяти всего. Описывается vsz.
