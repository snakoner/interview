**1. Сигналы**

Когда сигнал послан процессу, ядро Linux прерывает выполнение процесса (важно, что в этот момент процесс выполнятеся, то есть глобальные переменные в обработчике доступны). При этом, если процесс установил собственный обработчик сигнала, операционная система запускает этот обработчик, передав ему информацию о сигнале, если процесс не установил обработчик, то выполняется обработчик по умолчанию.

Сигналы могут посылаться:
1. из управляющего терминала:
- Ctrl+Z - **SIGTSTP** (terminal stop): приостановка выполнения сигнала, чтобы продолжить выполнение процесса нужно отправить **SIGCONT**
- Ctrl+/ - **SIGQUIT** - завершение с дампом памяти.
- Ctrl+C - **SIGINT** - по умолчанию завершает процесс, если не перегружен обработчик
2. Ядром Linux:
-  возникновении аппаратных исключений (недопустимых инструкций, нарушениях при обращении в память, системных сбоях)
-  ошибка при системном вызове
-  для информирования о событиях ввода-вывода
3. Одним процессом другому (или самому себе), с помощью системного вызова kill(), или из bash/kill


Обработчик по умолчанию для большинства сигналов завершает выполнение процесса. Нельзя перегрузить SIGKILL(немедленное завершение), SIGSTOP(приостановка).
Сигналы не могут быть посланы зомби-процессу.
