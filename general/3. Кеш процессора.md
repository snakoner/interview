## Типы промахов

1. Compulsory Misses - обычный кеш промах, когда данных в кеше нет. Такое случается, когда процесс только запустился.
2. Capacity miss - в кеше нет свободного места, все линии заняты
3. Conflict miss - линия, в которую хотим поместить новые данные, занята.

# MESI Protocol
Для сохранения целостности данных необходимы протоколы синхронизации кешей каждого кеша каждого процессора(сache coherency protocol[когерентность кэша] — свойство кэш-памяти, означающее целостность данных, хранящихся в локальных кэшах разделяемой системы).
