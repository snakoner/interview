# 1. Межпроцессное взаимодействие

**Межпроцессное взаимодействие**(Inter-process communication (IPC)) — это набор методов для обмена данными между потоками процессов. Процессы могут быть запущены как на одном и том же компьютере(локальное взаимодействие), так и на разных, соединенных сетью(сетевое взаимодействие).

Виды:
1. Каналы (pipes):
    1. именнованные(fifo)
    2. неименованные(pipes)
2. Разделяемая память(самый быстрый способ - диапазон адресов отображается на адресное пространство двух процессов, когда процесс изменяет память в этом участке - он одновременно изменяет память второго процесса).
3. Семафоры
4. Файлы(обмен данными через совместно используемые файлы)
5. Сигналы (некий аналог процессорных прерываний)
6. Очередеи сообщений
7. Сокеты


## Каналы

Бывают именованные и неименованные. Их отличие в том, что:
1. именнованный канал не удаляется после завершения процесса, который его создал. Неименнованный существует, пока процесс не завершится.
2. неименнованный канал является односторонним: в один pipe можно только писать, из другого pipe можно только читать.

### Неименованный канал:
```cpp
int pipe(int pipefd[2]); // pipefd[0] - дескриптор для чтения, pipefd[1] - дескриптор для записи
```

Запись в канал:
```cpp
write(pipefd[1], "Hello", 5);
```

Чтение из канала:
```cpp
char buf[50];
read(pipefd[0], buf, 50);
```

### Именованный канал
Именованные каналы обладают именем в пространстве файловых имен. Для создания используется функция mkfifo:
```cpp
int mkfifo(const char *pathname, mode_t mode);
```

Функция создает специальный FIFO файл с именем `pathname`, а параметр mode задает права доступа к файлу. Как только файл создан, любой процесс может открыть этот файл для чтения или записи также, как открывает обычный файл. 

## Разделяемая память

**Разделяемая память** позволяет нескольким процессам получать доступ к одной и той же области памяти, обеспечивая быструю и эффективную связь между ними. Вместо использования более медленных методов межпроцессного взаимодействия, таких как каналы или сокеты, разделяемая память обеспечивает прямой доступ к общим данным, что приводит к повышению производительности.

Выделение(или открытие[отображение на адресное пространство процесса], если такая память уже существует) разделяемой памяти:
```cpp
int shm_open(const char *name, int oflag, mode_t mode); // `mode` задает права доступа для пользователей, групп, `oflag` права доступа для процессов.
```

Целостность объекта памяти сохраняется, включая все данные связанные с ним, до тех пор пока объект не отсоединен/удален (`shm_unlink()`). Это означает, что любой процесс может получить доступ к нашему объекту памяти (если он знает его имя) до тех пор, пока явно в одном из процессов мы не вызовем `shm_unlink()`:

```cpp
int shm_unlink(const char *name);
```

Функция `shmget` выделяет новый сегмент разделяемой памяти или извлекает существующий на основе ключа. 
С другой стороны, `shmat` присоединяет сегмент разделяемой памяти к адресному пространству вызывающего процесса.

```cpp
int shmget(key_t key, size_t size, int shmflg);
void *shmat(int shmid, const void *shmaddr, int shmflg);
```

Функция `shmdt` удаляет сегмент общей памяти из адресного пространства вызывающего процесса:
```cpp
int shmdt(const void *shmaddr);
```

## Семафоры

Есть два типа семафоров:
1. Счетный семафор (counting semaphore), определяющий лимит ресурсов для процессов, получающих доступ к ним
2. Бинарный семафор (binary semaphore), имеющий два состояния «0» или «1» (чаще: «занят» или «не занят»)

### Счетный семафор

Смысл семафора со счетчиком в том, чтобы дать доступ к какому-то ресурсу только определенному количеству процессов. Остальные будут ждать в очереди, когда ресурс освободится.

Создание семафора:
```cpp
sem_t *sem_open(const char *name, int oflag, mode_t mode, unsigned int value); // value - начальное значение семафора
```
Захват и освобождение семафора:

```cpp
int sem_wait(sem_t *sem); // lock
int sem_post(sem_t *sem); // unlock
```

Удаление семафора:
```cpp
int sem_unlink(const char *name);
```
