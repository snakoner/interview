# 4. Структуры данных ядра

## Однонаправленный список

> Список list_head является циклическим.

В Linux, в отличие от привычного подхода к реализации списков, используется уникальный подход. Структура, описывающая узел списка, встраивается в саму структуру данных, которую необходимо добавить в список.

```cpp
struct list_head {
    struct list_head *next
    struct list_head *prev;
};
```

Пусть есть структура `struct fox`:

```cpp
struct fox {
    unsigned long tail_length;
    unsigned long weight; 
    bool is_fantastic; 
    struct list_head list; /* Список всех структур типа fox */
};
```

С помощью макроса container_of можно получить указатель на начало интересующей структуры (ptr - указатель на поле структуры, type - struct Name, member - имя поля, на который есть указатель):

```cpp
#define container_of(ptr, type, member) ({ \
    const typeof( ((type *)0)->member ) *__mptr = (ptr); \
    (type *)( (char *)__mptr - offsetof(type,member) );})
```

Имея указатель на элемент list структуры fox, можно получить саму структуру fox:
```cpp
struct list_head *ptr = &(f->list);
struct fox *f = container_of(ptr, struct fox, list);
```


### Инициализация связного списка

В случае динамического созданий структуры, инициализировать список можно так:

```cpp
struct fox *red_fox;
red_fox = kmalloc(sizeof(*red_fox), GFP_KERNEL);
red_fox->tail_length = 40;
red_fox->weight = 6;
red_fox->is_fantastic = false;

INIT_LIST_HEAD(&red_fox->list);
```

В случае статического создания структуры:

```cpp
struct fox red_fox = {
    .tail_length = 40,
    .weight = 6,
    .list = LIST_HEAD_INIT(red_fox.list),
};
```
Осталось только создать указатель на head данного списка fox_list:
```cpp
static LIST_HEAD(fox_list);
```

`LIST_HEAD` инициализирует переменную `fox_list` типо `list_head`. Сейчас список пуст, но теперь в него можно добавлять элементы типа `list_head`.

### Работа со списками

Вставка элемента new после элемента head:
```cpp
list_add(struct list_head *new, struct list_head *head)
```

Вставка элемента new перед элементом head:
```cpp
list_add_tail(struct list_head *new, struct list_head *head)
```

Удаление элемента из списка(память не освобождается):
```cpp
list_del(struct list_head *entry)
```
Удаление элемента из списка с его последующей инициализацией(prev, next указывают сами на саму ноду, что говорит о том, что элемент не находится ни в каком из списков):
```cpp
list_del_init(struct list_head *entry)
```

Перемещение узла из одного списка в другой (вставляется после head):
```cpp
list_move(struct list_head *list, struct list_head *head)
```
Перемещение узла из одного списка в другой (вставляется перед head, то есть в конец):
```cpp
list_move_tail(struct list_head *list, struct list_head *head)
```

Проверить, что список пуст:
```cpp
list_empty(struct list_head *head)
```

Cлить воедино два несвязанных между собой списка(list помещается после head):
```cpp
list_splice(struct list_head *list, struct list_head *head)
```

### Проход по списку

Пройтись по списку, пока все элементы не будут перебраны:
```cpp
list_for_each(p, &fox_list) {
    /* p указывает на элемент списка */
}
```
Для получения сразу структуры в цикле:

```cpp
struct fox *f;

list_for_each_entry(f, &fox_list, list) {
/* На каждой итерации цикла в переменной 'f'
содержится указатель на текущую структуру типа fox. */
}
```

## Очередь

Определение очереди находится в файле `linux/kfifo.c`. Реализована с помощью динамически выделенного массива размера size и двух указателей на начало и конец очереди.

Диманическое выделение:
```cpp
struct kfifo fifo;
int size = 10;
ret = kfifo_alloc(&fifo, size, GFP_KERNEL);
```

Постановка в очередь:
```cpp
unsigned int kfifo_in(struct kfifo *fifo, const void *from, unsigned int len);
```

Если места под элемент меньше, то будет скорировано доступное число байт и это значение вернется из функции.

Выборка из очереди:
```cpp
unsigned int kfifo_out(struct kfifo *fifo, void *to, unsigned int len);
```

Эта функция копирует не больше, чем len байт в to. При этом данные из очереди удаляются навсегда.

Чтение данных из очереди по индексу(offset) от начала очереди без удаления:
```cpp
unsigned int kfifo_out_peek(struct kfifo *fifo, void *to, unsigned int len,
unsigned offset);
```

Перед записью бывает полезно проверить количество доступных байт в очереди:
```cpp
static inline unsigned int kfifo_avail(struct kfifo *fifo);
```

## Двоичные деревья поиска

В Linux реализована с помощью rbtree: `linux/rbtree.h`.

Создание корня дерева:

```cpp
struct rb_root root = RB_ROOT;
```

Узлы описываются структурой `rb_node`.
