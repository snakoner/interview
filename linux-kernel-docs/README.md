## Questions
### 1. Можно ли прерывать обработчик прерывания

Обработчик прерывания выполняется при:
a) Всегда: Отключенной линии прерывания текущего прерывания для всех процессоров.
б) Не всегда: Отключаются все прерывания на процессоре, выполняющем текущее прерывание, если обработчик регистрировался с IRQF_DISABLED.

Поэтому обработчик прерывания может быть прерван на текущем процессоре другим обработчиком, но не тем же.

### 2. Почему обработчик прерывания нельзя заблокировать?
Потому что они не обрабатываются шедулером.
