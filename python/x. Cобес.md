3.	Как работают is и ==?
> == (оператор равенства): проверяет значение двух объектов, т.е. сравнивает их содержимое.
> is (оператор идентичности): оператор is проверяет идентичность объектов в памяти (то есть, указывают ли переменные на один и тот же объект).
```python
x = [1, 2, 3]
y = x  # y ссылается на тот же объект, что и x

print(x is y)  # True, так как обе переменные указывают на один и тот же объект в памяти
```

7.	Что делает zip()?

> Объединение нескольких итерируемых объектов:
```python
a = [1, 2, 3]
b = ['a', 'b', 'c']
result = zip(a, b)
print(list(result))  # [(1, 'a'), (2, 'b'), (3, 'c')]
```

9.	Как передаются аргументы в функции — по значению или по ссылке?

Передается ссылка на объект. Но:
- Неизменяемые типы: int, float, str, tuple, frozenset: При передаче этих типов данных в функцию создаётся ссылка на объект, но так как они не могут быть изменены, любые изменения внутри функции не будут затрагивать оригинальный объект.
- Изменяемые типы: list, dict, set: При передаче этих типов данных в функцию передаётся ссылка на объект, и изменения, сделанные в объекте, отразятся на оригинальном объекте.


10.	Разница между deepcopy() и copy()?

> copy() — поверхностное копирование: Для неизменяемых объектов (например, числа или строки) создается новая ссылка.Для изменяемых объектов (например, вложенных списков или словарей) в новом объекте остаются ссылки на те же вложенные объекты, что и в оригинале. То есть, если вы измените вложенные объекты в копии, это отразится и на оригинале.

> deepcopy() - глубокое копирование: она рекурсивно копирует все вложенные объекты

### Middle

11.	Что такое *args и **kwargs?

> *args позволяет функции принимать неопределённое количество позиционных аргументов. С помощью *args можно передавать любое количество аргументов, и они будут собраны в кортеж.
> **kwargs позволяет функции принимать неопределённое количество именованных (ключевых) аргументов. Они будут собраны в словарь, где ключи — это имена аргументов, а значения — переданные значения.

12.	Как работают замыкания (closures)?
> Замыкания позволяют функции использовать переменные из внешних функций, даже если они уже завершили выполнение
```python
def outer_function(x):
    # Переменная x - это свободная переменная для inner_function
    def inner_function(y):
        return x + y
    return inner_function

closure = outer_function(10)  # outer_function выполняется и возвращает функцию inner_function
print(closure(5))  # 10 + 5 = 15
```

13.	Что делают декораторы @staticmethod, @classmethod и @property?

- @staticmethod используется для создания статического метода в классе. Статический метод не зависит от состояния экземпляра класса и может быть вызван как через сам класс, так и через экземпляр.
- @classmethod используется для создания метода класса. Он принимает класс в качестве первого аргумента, обычно называемого cls, вместо экземпляра (self).
- @property позволяет превращать метод в свойство. Это значит, что метод можно вызывать как атрибут, не используя круглые скобки, и он будет вести себя как обычный атрибут, но с возможностью добавления логики.

- self — это первый параметр метода экземпляра (методы, которые относятся к конкретным объектам класса). Он ссылается на сам объект (экземпляр класса), для которого был вызван метод.

- cls — это первый параметр метода класса (методы, которые относятся к самому классу, а не к его экземплярам). Он ссылается на сам класс, и через него можно работать с атрибутами и методами класса.

```python
class MyClass:
    class_variable = 0  # Атрибут класса

    @classmethod
    def increment_class_variable(cls):
        cls.class_variable += 1  # Доступ к атрибуту класса
        print(cls.class_variable)

# Вызов метода класса
MyClass.increment_class_variable()  # 1
MyClass.increment_class_variable()  # 2
```

15.	Что такое MRO (Method Resolution Order)?

> MRO помогает избежать проблем, связанных с множественным наследованием
```python
class A:
    def method(self):
        print("Method from A")

class B(A):
    def method(self):
        print("Method from B")

class C(A):
    def method(self):
        print("Method from C")

class D(B, C):
    pass

d = D()
d.method() # Method from B
```

Python использует MRO для поиска метода в следующем порядке: сначала в классе D, затем в классе B, потом в классе C, и в последнюю очередь в классе A.
