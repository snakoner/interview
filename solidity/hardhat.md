### Настройка нового проекта
```
npm init --yes
```

```
npm install --save-dev hardhat
```

```shell
npx hardhat init  # выбрать ts
```

Компиляция всех контрактов:
```
npx hardhat compile
```

Очистка старых скомпилированных версий:
```
npx hardhat clean
```

Тестирование:
```
npx hardhat test
```
