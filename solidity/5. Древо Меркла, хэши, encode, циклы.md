### Merkle tree

Пусть есть блок, в котором есть 8 транзакций (2**n): 
```
T1  T2  T3  T4  T5  T6  T7  T8
```

Для каждой транзакции считается хеш (он называется листком):  \
```
H1  H2  H3  H4  H5  H6  H7  H8
|    |  |   |   |   |   |   |
T1  T2  T3  T4  T5  T6  T7  T8
```

Далее мы конкатенируем два соседних хеша и для них считаем хеш `Hnm`:  \
```
 H12     H34      H56    H78
/  \    /    \   /  \    /  \
H1  H2  H3  H4  H5  H6  H7  H8
|    |  |   |   |   |   |   |
T1  T2  T3  T4  T5  T6  T7  T8
```

Доходим до корня:  \
```
           Hroot
      /            \
    H1234          H5678
  /      \        /      \
 H12     H34      H56    H78
/  \    /    \   /  \    /  \
H1  H2  H3  H4  H5  H6  H7  H8
|    |  |   |   |   |   |   |
T1  T2  T3  T4  T5  T6  T7  T8
```

Предположим, что нам нужно удостовериться, что T5 присутствует в блоке. Для этого мы считаем H5, потом берем H6 и считаем H56, берем H78 и считаем H5678, берем H1234 и считаем Hroot. Если они совпадают, то транзакция присутствует:\

```
           Hroot
      /            \
  [H1234]        [H5678]
  /      \        /      \
 H12     H34      H56    [H78]
/  \    /    \   /  \    /  \
H1  H2  H3  H4 [H5] [H6]  H7  H8
|    |  |   |   |   |   |   |
T1  T2  T3  T4  T5  T6  T7  T8
```

Реализация древа Меркла на solidity:
```solidity

contract MerkleTree {
    bytes32[] public hashes;
    string[4] transactions = [
        "tx1",    
        "tx2",    
        "tx3",    
        "tx4"    
    ];

    constructor() {
        for (uint i = 0; i < transactions.length; i++) {
            hashes.push(makeHash(transactions[i]));
        }

        uint count = transactions.length;
        uint offset = 0;
        while (count > 0) {
            for (uint i = 0; i < count - 1; i += 2) {
                hashes.push(keccak256(
                    abi.encodePacked(
                        hashes[offset + i], hashes[offset + i + i]
                    )
                ));
            }

            offset += count;
            count = count / 2;
        }
    }

    function makeHash(string memory input) public pure returns(bytes32) {
        return keccak256(
            abi.encodePacked(input) // судя по всему просто представление в ascii
        );
    }

    function verify(
        string memory transaction, 
        uint index,
        bytes32 root,
        bytes32[] memory proof  // список хешей, нужных для того чтобы посчитать hroot
        
    ) public pure returns (bool) {
        bytes32 hash = makeHash(transaction);
        for (uint i = 0; i < proof.length; i++) {
            bytes32 element = proof[i];
            if (index % 2 == 0) {
                hash = keccak256(abi.encodePacked(hash, element));
            } else {
                hash = keccak256(abi.encodePacked(element, hash));
            }

            index = index / 2;
        }

        return hash == root;
    }
}

```
