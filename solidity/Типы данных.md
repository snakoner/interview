## Типы данных

### Value types

Такие значения всегда передаются по значению при вызове функций.

#### bool

Значение по умолчанию: `false`.
Может принимать значения `true`, `false`. 

#### integers

Сейчас в sol нет поддержки чисел с плавающей запятой, есть только целочисленная арифметика.

Есть два типа: signed, unsigned (`int`/`uint`).

- `uint` - alias для `uint256`
- `int` - alias для `int256`

Минимально возможный тип: uint8/int8. Далее идут типы с шагом 8: `uint16`/`int16`, `uint24`/`int24`...

Что будет есть переполнить? Solidity не даст этого сделать и сделает revert. 

Но можно использовать ключевое слово unchekced, которое будет отлавливать переполнения и вернет значение переменной к минимальному значению:

```sol
uint8 value = 0;

function inc() public {
  unchecked {
    value++;    // 255 -> 0
  }
}
```

### string

```sol
contract Variables {
  string public str = "test";
}
```

Как передавать в функцию?

```sol
contract Variables {
  string public str = "test";
  function demo(string memory newValue) {
    str = newValue;
  }
}
```

Тонкости:
- Строки нельзя склеивать
- Нельзя обращаться по индексу
- Нельзя получить длину строки

### mapping

Ключами могут быть address, string, integers, bool.

Значениями могут быть любые типы данных.

Нельзя получить список ключей в mapping, по умолчанию считается, что все ключи есть с дефолтным значением.

```sol
contract Variables {
  mapping (address => uint) public balances;

  function receiveFunds() public payable {
    balances[msg.sender] += msg.value;  // value доступен, только если функция помечена как payable
  }
}
```

### Reference type

#### Enums

```sol
contract Variables {
  enum Status {Paid, Delivered, Received}; // 0 1 2
  Status public status;

  function func() public {
    status = Status.Paid;
  }
}
```

#### Arrays

Есть массивы с фиксированной длиной и динамические:

```sol
contract Variables {
  uint[10] public items = [1,2,3]; // оставшиеся элементы - значения по умолчанию
  string[5] public strs;
  uint[3][2] public items2;  // 2 x 3, наоборот в отличие от других языков

  function func() public {
    items[0] = 100;
  }
}
```

```sol
contract Variables {
  uint[] public items;

  function func() public {
    items.push(1);
    items.push(2);  // 1 2

    uint len = items.length;  // 2
  }

  // хранение в memory
  function memorySample() public view returns (uint[] memory) {
    uint [] memory it = new uint[](10);

    return it;
  }
}
```

#### struct 
Полями могут быть любые типы, кроме самого типа: (в Payment не может быть поле Payment).

```sol
contract Variables {
  struct Payment {
    string message;
    uint amount;
    address from;
  }

  mapping(address => Payment) public balances;

  function pay(string memory message) public payable {
    Payment memory newPayment = Payment(
      message,
      msg.value,
      msg.sender
    );

    balances[msg.sender] = newPayment;
  }

}
```
