### Inherritance

- `SelfManagedFactory` - factory for creating clones
- `SelfManagedDefii` -> `SelfManagedDefiiV4` - template for clones, clone from this contract
- `SelfManagedLogic` - abstract for logic for certain Strategy implementation
- `SelfManagedLogicWithUtils` - is inherrited from SelfManagedLogic, new funcs is _approveIfNeeded, _transferAll, inherritence for common strategies like AaveV3, Accros

- TEMPLATE: `SelfManagedDefii`->`SelfManagedDefiiV4`
- LOGIC: abstract contract `SelfManagedLogic` -> abstract contract `SelfManagedLogicWithUtils` -> ConvexCurveArbitrum / Across / DodoV2 / AaveV3
- IMPL: contract `AaveV3` -> `AaveV3EthereumUSDC`
