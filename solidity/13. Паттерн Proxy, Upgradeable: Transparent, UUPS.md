Идея: взаимодействие с контрактом ведется не напрямую, а через посредника - прокси:

```
User --- tx ---- Proxy ---- | ----- Impl_V0
                            | ----- Impl_V1
                            | ----- Impl_V2
```

Работает через delegate call: логика лежит в Implementation, данные в Proxy.
