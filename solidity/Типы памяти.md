### Типы памяти

У всех типов памяти тип записи big endian.

- stack: direct
- storage: direct
- memory: reference
- calldata: reference, !mapping
- code: constant / immutable

Виды данных:
- direct (uintN, bytesN, bool, address, enums, internal/external funcs)
- miltivalue (type[N], struct)
- lookup (type[N], mapping, bytes, string)



- static (direct, multivalue)
- dynamic (!static)
- reference (multivalue / lookup)

В storage direct данные хранятся в packed виде, то есть упаковываются в слоты: например, 
есть есть два uint128, то они попадут в один слот, который 256 бит.

В memory / calldata / code - padded хранение, то есть каждый тип хранится

#### stack

Стек используется при выполнении функций. 
На нем EVM выполняет вычисления. Напрямую обращаться к нему нельзя, 
к нему может быть обращаться только EVM. После завершения выполнения функции стек очищается

Может хранить только типы `direct`.

#### code
Конструктор не попадает в code. Здесь хранится код контракта, кроме того здесь хранятся `const`, `immutable`.

#### memory

Могут храниться direct, reference, multivalue(), lookup (перед дин массивом идет длина, потом его данные).
Также сюда попадают постоянные переменные во время деплоя контракта, пока они не попали в байткод.
memory используется, чтобы хранить временные данные при выполнении функции.

#### calldata
Могут храниться типы direct, reference, !mapping.
Первые 4 байта - селектор функции, которая вызывается, далее идут аргументы. Доступна только для чтения.

#### storage

Может хранить mapping, direct, reference, lookup.

Размечается во время деплоя контракта. Нельзя создать самому новый слот в storage в функции. 
Если происходит наследование, то переменные базового класса будут располагаться перед переменными дочернего.

##### Как хранятся byte arrays?

Если длина bytes < 32 байта, то [len][data], если >, то аналогично динамическому массиву.

##### Как хранятся динамические массивы? 

Длина массива занимает один слот, который называется главным слотом. 
Пусть номер данного слота p. Для того, чтоб получить слот, где лежат первые данные, вычисляется keccak256(p), 
потом этот хеш преобразуется к числу - номер слота начала хранения данных массива.

##### Как хранятся mapping?

У mapping тоже есть главный слот, который пустой. Конкатенируется (key # p) и считается keccak256 от этого значения.
И на этом слоте получаем value
