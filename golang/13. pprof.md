**pprof** – это инструмент для профилирования производительности Go-приложений. Он помогает находить узкие места в CPU, памяти, блокировках и конкурентности.

### Подключение pprof в код

```golang
package main

import (
	"log"
	"net/http"
	_ "net/http/pprof" // Встроенный пакет для профилирования
)

func main() {
	go func() {
		log.Println(http.ListenAndServe("localhost:6060", nil))
	}()

	// Основное приложение...
	select {} // Бесконечный процесс
}
```

#### Запуск CPU профилирования:

> go tool pprof http://localhost:6060/debug/pprof/profile // По умолчанию он собирает 30 секунд CPU-активности, после запуска команды вы окажетесь в интерактивной консоли pprof.

- top – показывает самые затратные функции
- list <func> – выводит исходный код и горячие участки
- web – строит граф (требуется Graphviz)
- svg – сохраняет граф в pprof.svg

#### Профилирование памяти (Heap)

> go tool pprof http://localhost:6060/debug/pprof/heap

- top – показывает, какие функции используют больше всего памяти
- list <func> – показывает выделения в конкретной функции

#### Какие горутины работают?

> curl http://localhost:6060/debug/pprof/goroutine?debug=1

#### Какие блокировки замедляют код?

> go tool pprof http://localhost:6060/debug/pprof/mutex

#### Какие задержки в GC?

> go tool pprof http://localhost:6060/debug/pprof/gc
