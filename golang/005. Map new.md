Есть ключ "user"
1. Считаем hash("user") = h = 0xA1B2C3D4E5F67890
2. Hash делится на H1 и H2:
- H1 = старшие биты // 57 бит
- H2 = младшие биты // 7 бит
3. По H1 выбирается стартовая группа
- Допустим в таблице сейчас: groupCount = 16
- groupIndex = H1 % 16 = 5
- Идем в Group5


4. Читаются control bytes группы
```
Group5

ctrl:

+------+------+------+------+------+------+------+------+

| 44   | 16   | E    | 71   | E    | E    | E    | E    |

+------+------+------+------+------+------+------+------+
```

5.
```
slot0 -> ctrl=44
slot1 -> ctrl=16
slot2 -> EMPTY
slot3 -> ctrl=71
```


#### Поиск удаление
Если прошли группу и там все занято, то идем в соседнюю, поиск происходит либо до нахождения, либо до первого свободного слота (что значит, что дальше ничего больше нет - нечего искать / удалять


В Swiss Map у control byte есть несколько состояний:
```
EMPTY      — слот никогда не использовался
FULL       — слот содержит элемент (в ctrl лежит H2)
DELETED    — tombstone
```

```
slot0: userA
slot1: userB
slot2: userC
```

После удаления userB:

```
slot0: userA
slot1: DEL // при поиске это не EMPTY - надо искать дальше
slot2: userC
```

#### Директории, таблицы
У каждой мапы есть globalDepth = N (directory хранит только ссылки на таблицы, ссылок 2^globalDepth).  Пусть N =  3 - для выбора таблицы используются 3 старших бита хеша. Пусть старшие 3 бита = 6.
```
directory[6]
0 -> TableA
1 -> TableA
2 -> TableB
3 -> TableB
4 -> TableC
5 -> TableC
6 -> TableD // таблица D
7 -> TableD

```


Увеличение размера:

```
directory

000 -> T0
001 -> T0
010 -> T1
011 -> T1
100 -> T2
101 -> T2
110 -> T3
111 -> T3
```

T1 переполнилась: runtime создает T1a, T1b:
```
directory

000 -> T0
001 -> T0

010 -> T1a // T1 перераспределяется в T1a
011 -> T1b

100 -> T2
101 -> T2

110 -> T3
111 -> T3
```
В новой Swiss Map рост происходит через split отдельных таблиц. Когда table переполняется, её содержимое перераспределяется между двумя новыми таблицами по дополнительному биту хеша. Если для split не хватает битов (localDepth == globalDepth), сначала удваивается directory и увеличивается globalDepth. Таким образом растёт не вся map целиком, а только проблемные части структуры.
