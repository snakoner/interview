По умолчанию:

```

123      // int
123.45   // float64
'a'      // rune (int32)
"hello"  // string
true     // bool

```

Проход по строке:

```go
s := "Привет"

for i := 0; i < len(s); i++ {
    fmt.Println(i, s[i])
}

// 0 208
// 1 159
// 2 209
// 3 128
...
```

```go
s := "Привет"

for i, r := range s {
    fmt.Println(i, r)
}

// 0 П
// 2 р
// 4 и
// 6 в
// 8 е
// 10 т
```
