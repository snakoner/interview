### Junior

1. Что такое Go и в чем его основные преимущества?
	Go — это компилируемый язык программирования, разработанный Google. Его основные преимущества:
	- Простота и лаконичность синтаксиса
	- Высокая производительность (сравнима с C++)
	- Встроенная поддержка конкурентности (goroutines, channels)
	- Автоматический garbage collector
	- Кроссплатформенность

2. Чем отличается var от :=?
	- var используется для явного объявления переменной с указанием типа
	- := — короткое объявление переменной без явного указания типа, доступно для объявления только внутри функции

3. Как объявить и использовать массив в Go?
	```go
	arr := [3]int{}
	arr := [...]int{2,3,4,5} // сам определит размер
	var arr [3]int = [3]int{1,2,3}
	```

6. Как устроены строки в Go?

	В Go строка в является слайсом байт, доступным только для чтения. Строка содержит произвольные байты, и у неё нет ёмкости (cap).
	При преобразовании слайса байт в строку (str := string(slice)) или обратно (slice := []byte(str)) — происходит копирование массива.
	
	Go использует тип rune (алиас int32) для представления Unicode. Конструкция for ... range итерирует строку посимвольно (а не побайтово, как можно было бы предположить):
	
	```go
	var str = "привет"
	
	for i, c := range str {
	    fmt.Println(i, c, string(c))
	}
	
	// 0 1087 п
	// 2 1088 р
	// 4 1080 и
	// 6 1074 в
	// 8 1077 е
	// 10 1090 т

	fmt.Println(len(str)) // 12
	
	for i := 0; i < len(str); i++ {
	  fmt.Println(str[i]) // побайтово
	}
	```

 	Эффективным способом работы со строками (когда есть необходимость часто выполнять конкатенацию, например) является использование слайса байт или strings.Builder, который всегда использует один и тот же буфер.

7. Как увеличивается размер slice?

   	Добавление элемента в slice происходит при вызове slice = append(slice, value). Если len < cap, то append вернет копию с тем же ptr. Если len == cap, то выделится новая область памяти и append вернет копию slice, но уже с новым ptr.
   
	Увеличении размера слайса (метод growslice) происходит по следующему алгоритму — если его размер менее 1024 элементов, то его размер будет увеличиваться вдвое; иначе же слайс увеличивается на ~12.5% от своего текущего размера.

8. Какое у слайса zero value? Какие операции над ним возможны?

	nil

	```go
	 var a []int
	
	println(a == nil, len(a), cap(a)) // true 0 0
	a = append(a, 1)
	println(a == nil, len(a), cap(a)) // false 1 1
 	```
