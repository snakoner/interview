JWT — это компактный текстовый токен, который используется для авторизации и передачи информации между клиентом и сервером.

Он состоит из трёх частей, разделённых точками:
```
  header.payload.signature

  // пример (header, payload - base64)
  eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.
  eyJleHAiOjE3NTkyODg0NDksImlhdCI6MTc1OTI0NTI0OSwiaWQiOiJtaW50ZXJfYW5kcmV5In0.
  SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c
```

#### Header
```
// decode eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9
{
  "alg": "HS256", // алгоритм подписи
  "typ": "JWT" // тип токена
}
```

#### Payload
```
// decode eyJleHAiOjE3NTkyODg0NDksImlhdCI6MTc1OTI0NTI0OSwiaWQiOiJtaW50ZXJfYW5kcmV5In0

{
  "exp": 1759288449,  // время экспирации
  "iat": 1759245249, // время генерации
  "id": "minter_andrey" // custom parameter
}
```

#### Signature

```
HMACSHA256(base64url(header) + "." + base64url(payload), secret_key)
```

#### Как это работает
1. Пользователь вводит login/password. Сервер проверяет их и создаёт JWT с данными пользователя (id, роли, срок жизни).
JWT возвращается клиенту (в Authorization header или cookie).

2. Клиент при каждом запросе к API отправляет токен:
```
Authorization: Bearer <jwt_token>
```

3. Сервер берёт токен, проверяет подпись (signature) с помощью секретного ключа.
- Проверяет exp (время жизни).
-	Если подпись совпала → токен не подделан.
- Достаёт данные пользователя из payload.
