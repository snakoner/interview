2. Что происходит если goroutine делает syscall?
```

```
- Thread блокируется.
- Runtime отвязывает P: M1 <- P 
- Привязывает к другому потоку: M2

3. Почему это опасно:
```
func f(s []int) {
	s = append(s, 1)
}
```
- Не возвращаем из функции s = f(s), по факту ничего не поменяется, но в backing array добавится элемент, если len < cap
- Если len = cap - реаллокация, тоже ничего не изменится
