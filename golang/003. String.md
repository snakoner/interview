### strings.Builder

Обёртка над []byte для эффективного построения строк. 

Методы: 
```
Grow(n int) - сразу выделяет память на n байт
WriteString(s string) — добавляет строку. 
Write(p []byte) - добавляет массив байт. 
WriteByte(c byte) - добавляет один байт. 
WriteRune(r rune) - добавляет символ (руну). 
Len() - возвращает текущий размер буфера в байтах. 
Cap() - возвращает текущий капасити буфера в байтах. 
Reset() — очищает буфер для повторного использования. (nil оба поля) 
String() - собирает и возвращает строку. 
```

Когда лучше использовать "Builder": 
- Многократная конкатенация в цикле. 

Когда можно использовать "+": 
- Если строки создаются одним шагом, компилятор оптимизирует и не делает лишних аллокаций.

```go
type Builder struct {
    addr *Builder // Оно используется для защиты от копирования Builder по значению. 
    buf  []byte
}
```

```
func (b *Builder) copyCheck() {
    if b.addr == nil {
        b.addr = b
    } else if b.addr != b {
        panic("strings: illegal use of non-zero Builder copied by value")
    }
}
```
