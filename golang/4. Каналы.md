### Каналы в go

`Канал` - объект, с помощью которого горутины могут обмениваться данными. Из канала можно читать и писать (по умолчанию). Каналы бывают буфферизированными и небуфферизированными.
Каналы являются потокобезопасными (можно работать с ними без использования блокировок, так как блокировки есть внутри структуры канала).



#### Аксиомы каналов
1. Запись в неинициализированный канал блокирует горутину навсегда
2. Чтение из неинициализированного канала блокирует горутину навсегда
3. Запись в закрытый канал вызывает panic
4. Чтение из закрытого канала возвращает 0 значение
