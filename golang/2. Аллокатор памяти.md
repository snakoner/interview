### Возвращение указателя из функции

Рассмотрим следующий пример:
```go
func main() {
  x := getValue()
  fmt.Println(x)
}

func getValue() *int {
  x := 4
  return &x
}
```

В отличие от языка C/C++, где при возвращении указателя из функции он бы остался в предыдущем стек-фрейме и 
вызов `fmt.Println()` бы его перетёр, в go компилятор разместит `x := 4` на heap.

Перетаскивает объектов из stack в heap называется `escape-analysis`.

Вот случаи, когда компилятор go размещает переменные на heap, а не в stack:
1. Возврат указателя на локальную переменную из функции.
2. Переменная передается в функцию как тип `interface{}`
3. Если память, занимаемая переменной больше чем лимит stack.
