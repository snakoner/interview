#### 1. В чем отличие var value T, value :=?
- var value T - можно объявить в глобальной области видимости, после объявления - zero value. Можно инициализировать не zero value, если сделать var value T = ...
- value := - можно объявить только в функции, инициализируется значением после :=

## Slice, array
### 1. Как устроены array, slice. Что возвращает append?
array:
- компилятор на этапе компиляции знает длину
- в значении хранятся N элементов подряд
- при передаче в функцию - копирование
  
slice:
- на стеке: (ptr, len, cap)
- при передаче в функцию - копирование, но так как копируется и ptr - указывает на ту же область памяти, можно модифицировать, если не будет append'ов

### 2. Нужно ли передавать slice по указателю в функцию, если мы хотим поменять порядок следования элементов. А если хотим делать append.
1: нет, 2: да, так как возможна реаллокация памяти при len == cap

### 3. Что будет, если size == cap, и мы хотим сделать append. 
Выделение новой области памяти 2*cap (рост до cap = 1024 в два раза, далее ?)
