Что такое interface под капотом?

Это контракт (набор методов, который должен реализовывать тип)

Интерфейс хранит две вещи:
```
(type, value)
```

```go
var r io.Reader // (type = nil, value = nil)
var f *os.File
var r io.Reader = f // (type = *os.File, nil)
```

```go
var p *MyStruct = nil
var i interface{} = p
fmt.Println(i == nil) // false, так как i.type = *MyStruct
```


#### Чем interface{} отличается от any?
Ничем, С Go 1.18:

```
type any = interface{}
```

#### Почему в Go рекомендуют маленькие интерфейсы?

```
// хорошо
type Reader interface {
	Read([]byte) (int, error)
}

// плохо
type MegaService interface {
	Create()
	Update()
	Delete()
	Send()
	Log()
	...
}
```

Потому что маленькие интерфейсы:
- проще реализовать;
- проще мокать;
- меньше связанность.

#### Кто должен объявлять интерфейс:

```
// Плохо
package db

type Repository interface {
	Get()
	Save()
}

// Хорошо
package service
type UserGetter interface {
	Get(id int64)
}
```

Интерфейс нужно объявлять в месте использования

#### Error
```
type error interface {
	Error() string
}

// Любой тип с методом: Error() string - становится ошибкой



```
