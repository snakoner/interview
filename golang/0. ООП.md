1. Инкапсуляция - сокрытие внутреннего состояния объекта и управление доступом к нему через интерфейс (методы) , можем к нему обратиться только из этого пакета.


В go - через экспортируемые и неэкспортируемые поля:
```go
type User struct {
  Age int
  name string
}

// Из другого пакета:
user := User{}
fmt.Println(user.Age) // ok
fmt.Println(user.name) // compile error

```

2. Наследование - сущность наследует поля и методы другой сущности.

В go - нет, но есть embedding

```go
type User struct {
	Name string
}

func (u *User) SayHello() {
	fmt.Println("Hello, my name is", u.Name)
}

type Person struct {
	User
}

func main() {
	person := Person{
		User: User{
			Name: "John",
		},
	}

	fmt.Println(person.Name)
	person.SayHello()
}
```

3. Полиморфизм - Единый интерфейс - разные реализации

В go - есть, интерфейсы:

```go
type Animal interface {
	SayHello()
}

type Dog struct {
	Name string
}

func (d *Dog) SayHello() {
	fmt.Println("Hello, i'm a dog and my name is", d.Name)
}

type Cat struct {
	Name string
}

func (c *Cat) SayHello() {
	fmt.Println("Hello, i'm a cat and my name is", c.Name)
}

func main() {
	dog := Dog{Name: "Rex"}
	cat := Cat{Name: "Barsik"}

	dog.SayHello()
	cat.SayHello()
}
```
