### Options
Удобная настройка объекта без огромного конструктора.

```go
type Server struct {
	host    string
	port    int
	timeout time.Duration
}

type Option func(*Server)

func WithHost(host string) Option {
	return func(s *Server) {
		s.host = host
	}
}

func WithPort(port int) Option {
	return func(s *Server) {
		s.port = port
	}
}

func WithTimeout(timeout time.Duration) Option {
	return func(s *Server) {
		s.timeout = timeout
	}
}

func NewServer(opts ...Option) *Server {
	s := &Server{
		host:    "127.0.0.1",
		port:    80,
		timeout: 3 * time.Second,
	}

	for _, opt := range opts {
		opt(s)
	}

	return s
}
```

### Semaphore
Semaphore ограничивает количество одновременно выполняемых операций. (10000 горутин, но N выполняются одновременно)
```go
func main() {
	sem := make(chan struct{}, 3)
	var wg sync.WaitGroup

	for i := 1; i <= 10; i++ {
		wg.Add(1)

		go func(id int) {
			defer wg.Done()

			sem <- struct{}{}
			defer func() { <-sem }()

			fmt.Println("start", id)
			time.Sleep(time.Second)
			fmt.Println("done", id)
		}(i)
	}

	wg.Wait()
}
```

### Worker pool
1000 задач, но N воркеров (всего N горутин запущено)
```go
func worker(id int, jobs <-chan int, results chan<- int) {
	for job := range jobs {
		fmt.Println("worker", id, "processing", job)
		results <- job * 2
	}
}

func main() {
	jobs := make(chan int)
	results := make(chan int)

	workerCount := 3

	for i := 1; i <= workerCount; i++ {
		go worker(i, jobs, results)
	}

	for i := 1; i <= 10; i++ {
		jobs <- i
	}
	close(jobs)

	for i := 1; i <= 10; i++ {
		fmt.Println(<-results)
	}
}
```



### Inbox pattern / Outbox pattern

Inbox защищает consumer от повторной обработки сообщений (допустим Kafka два раза прислала одно сообщение, смотрим в бд обработано ли оно и если да, то skip)

Outbox нужен, чтобы надежно отправлять события после изменения БД. (Событие -> пишем в бд в sent = false, отправили в брокер -> sent = true. Нужен, если kafka отвалится)

### Fan in / Fan out
Fan out - Несколько goroutine читают из одного источника задач. (Worker pool - реализация)

Fan in - несколько горутин пишут в один канал - сборка результатов:

```
worker1 \
worker2  ---> results
worker3 /
```

### Singleton
Один экземпляр объекта гарантируется.

```
var (
	instance *DB
	once sync.Once
)

func GetDB() *DB {
	once.Do(func() {
		instance = NewDB()
	})
	return instance
}
```

### Factory
Создание объектов без раскрытия реализации.

```
type Storage interface {
	Save([]byte) error
}

func NewStorage(kind string) Storage {
	switch kind {
	case "s3":
		return &S3Storage{}
	case "local":
		return &LocalStorage{}
	}

	return nil
}
```

### Builder
Есть Client и ClientBuilder
```
type Client struct {
	name string
}

type ClientBuilder struct {
	c *Client
}

func NewClientBuilder() *ClientBuilder {
	return &ClientBuilder{
		c: &Client{},
	}
}

func (b *ClientBuilder) SetName(name string) *ClientBuilder {
	b.c.name = name
	return b
}

func (b *ClientBuilder) Build() *Client {
	return b.c
}

func main() {
	client := NewClientBuilder().SetName("John").Build()
	fmt.Println(client.name)
}
```
