# Компилятор golang

Рассмотрим программу на C:
```c
#include <stdio.h>

int main() {
  printf("Hello, world!");
}
```

После компиляции размер бинарного файла ~8KB.

Скомпилируем программу на golang:
```golang
package main

import "fmt"

func main() {
  fmt.Println("Hello, world!")
}
```

Размер бинарного файла ~2MB.

Что содержит бинарный файл?

> Runtime GO - код, который выполняется в программе, но который мы сами не вызывали. В него входят:
> 1. Планировщик
> 2. Сборщик мусора
> 3. Аллокатор памяти

> Обширная стандартная библиотека

> Отладочная информация

### Планировщик
Планировщик управляет горутинами. 

Зачем нужны горутины? \
Стандартные потоки ОС тяжелые и медленные. 

Отличие потоков от горутин:
```bash
                Threads                      Goroutines
Управляются:    Планировщиком OS             Планировщиком Go, который входит в рантайм Go
Объем           ~1-2MB                       ~2KB
Переключение    Медленное переключение       Более быстрое переключение контекста
контекста:

Способы взаимодействия:    IPC               Более кыстрые каналы
```
