### Что такое Map

Абстарктная структура данных, которая может выполнять: вставка, удаление, удаление элемента по ключу. Операция должна выполняться за константное время.

```go
map[key_type]value_type
```

В Go обход map каждый раз происходит в случайном порядке, так как в методе lookup выбирается случайный бакет, с которого начинается обход (разработчики таким образом дают понять, что map unordered и чтобы разработчик не полагался на порядок).

В функцию map передается по значению, но из-за того что внутри указатели, просто передается копия того же указателя и map можно менять.

#### Интересные моменты
1. В качестве ключа можно использовать любой тип данных для которого определена операция сравнения. Например, можно использовать структуру с тем же условием для всех ее полей;
2. При отсутствии элемента возвращается нулевое значение для типа. Вторым параметром можно получить флаг наличия элемента по ключу;
3. Нельзя получить адрес элемента. Потому что при росте мапы оно переедет в другой бакет и адрес у него, соответственно, поменяется;
4. Мапа не безопасна для конкурентного использования. Для этого можно использовать обертку из sync.Map или мьютекс;
5. Порядок итерации не сохраняется. При каждой новой итерации мапы последовательность возвращаемых элементов может отличаться. Под капотом каждый раз выбирается рандомный бакет, с которого начинается итерация. Для сохранения нужного порядка придется сохранять ключи в отдельном массиве и итерироваться по нему;
6. При каждом создании мапы генерируется seed для рандомизации хэш-функции. Это сделано для безопасности, так как зная хэш-функцию можно подобрать такие ключи, что все значения попадут в один бакет и мы получим линейную скорость поиска;
7. При коллизиях используется стратегия сlosed addressing. Мы перебираем все ячейки бакета (их 8) и ищем первое свободное место;
8. OverloadFactor равен 6.5 (~81% заполненности бакетов). Когда бакеты в среднем заполнены больше чем на 6.5 элементов, тригерится рост мапы, и все элементы перемещаются в новые бакеты, которых создается в два раза больше.
9. При росте элементы переносятся в новые бакеты постепенно, а не все сразу;

#### Операции
```
  m := make(map[string]int)    // всегда нужно инициализировать, так как это ссылочный тип
  // m = map[string]int // так работать не будет
  m[k] = v   // добавление
  delete(m, k) // удаление ключ-значение
  v := m[k] // поиск: если такого ключа нет, вернется значение по умолчанию
  v, ok := m[k] // поиск: если такой ключ есть, то ok == true, иначе false
```

### Свойства хэш-функции
1. Равномерное распределение
2. Быстрота вычисления
3. Детерминированность
4. Криптоустойчивость(?)

### Map в Go
Map в Go - просто указатель на структуру типа `hmap`:

```go
// A header for a Go map.
type hmap struct {
	count     int // Число элементов в map
	flags     uint8
	B         uint8  // log_2 от числа бакетов (например B = 3 -> число бакетов: 8)
	noverflow uint16 // примерное число переполненных бакетов
	hash0     uint32 // seed для рандомизации хэшей, чтобы было сложнее подобрать и заddosить (добавить такие значения ключей, чтобы они попадали в один бакет)

	buckets    unsafe.Pointer // ссылка на массив из 2^B бакетов; nil, если count==0
	oldbuckets unsafe.Pointer // ссылка на массив предыдущих бакетов. в процессе роста мапы здесь будет массив старых бакетов, откуда потихоньку будут переноситься значения в новые бакеты.
	nevacuate  uintptr        // количество "эвакуированных" бакетов.

	extra *mapextra // optional fields
}
```
