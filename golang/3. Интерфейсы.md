### Интерфейсы

**Интерфейсы** - концепция языка go, по сути `определение`, которое описывает конкретные методы должны быть у какого-то другого типа.

Мы говорим, что тип данных удовлетворяет этому интерфейсу (или реализует этот интерфейс), если у этого типа данных есть методы с сигнатурами интерфейса.

**Пример**:

```go
type Stringer interface {
  String() string
}

type Book struct {
  Title string
  Author string
}

func (b *Book) String() {
  return fmt.Sprintf("%s - %s", b.Title, b.Author)
}
```

**Самое важное**: интерфейсный тип может быть переменной, полем структуры, аргументом функции. Поэтому можно присваивать/передавать любой тип данных, который удовлетворяет данному интерфейсу.

Пример:

```go
func Stringify(s Stringer) {
  fmt.Printf("%s", s.String())
}

func main() {
  b := Book{"A", "B"}
  Stringify(b) // stdout: "A - B"
}
```
